# 📖 카드결제 수동 취소 매뉴얼 (중복결제 · 포스 취소 불가 시)

#### 1️⃣ 이런 상황일 때 사용하세요

* **중복결제** — 같은 금액이 2번 승인된 경우 → 1건 취소 필요
* **포스 취소 불가** — 결제 당일이 지났거나, 전산 오류·단말기 문제로 포스에서 취소가 안 되는 경우

> ⚡ 순서: **① 포스에서 먼저 취소 시도 → ② 안 되면 이 매뉴얼대로 카드사에 전화**

***

#### 2️⃣ 영수증 준비 (필수)

해당 거래의 **카드 영수증을 출력**합니다. (포스 → 결제내역 조회 → 해당 거래 선택 → 영수증 재발행)

상담 시 영수증에서 확인해야 할 정보 4가지:

| 항목           | 영수증 표기 위치   |
| ------------ | ----------- |
| ① 카드사명 (매입사) | 영수증 상단      |
| ② 승인번호       | 승인번호 / 승인No |
| ③ 승인일시       | 거래일시        |
| ④ 결제금액       | 합계 금액       |

> 💡 카드번호 뒷 4자리까지 알면 상담이 더 빨라집니다.

#### 5️⃣ 상담 진행 (통화 스크립트)

아래 문장 그대로 말하면 됩니다. (사업자번호는 3️⃣ 표에서 자기 매장 것으로)

> "안녕하세요, **가맹점**입니다. **매출 취소** 요청드립니다. 사업자등록번호 **000-00-00000**, 대표자 **조병조**입니다. **○월 ○일 ○○시**, 승인번호 **○○○○○○**, 금액 **○○○원** 건인데 **중복결제**(또는 **단말기에서 취소가 안 되어서**) 취소 부탁드립니다."

* 상담원이 거래 확인 후 취소 처리해 줍니다.
* 처리 완료 시 **취소 확인 문자 또는 취소전표 발송을 꼭 요청**하세요.

***

#### 6️⃣ 취소 후 마무리 (필수 3가지)

1. **고객 안내** — "취소 완료되었고, 환불은 카드사에 따라 **3\~7영업일** 내 반영됩니다" (체크카드는 보통 더 빠름)
2. **증빙 보관** — 취소전표 또는 취소 확인 문자 캡처를 보관
3. **채널 보고** — 해당 매장 정산 채널(reports)에 `일시 / 금액 / 승인번호 / 취소 사유` 기록

***

#### ⚠️ 주의사항

* **BC카드는 특히 주의** — 당일 건은 포스 취소가 되지만, **하루가 지나면 포스에서 '취소 완료' 메시지가 떠도 실제로는 취소되지 않을 수 있습니다.** 반드시 전화(1588-4500)로 처리하세요.
* **취소 가능 기한** — 카드사별로 다르며 통상 승인일로부터 수개월 이내입니다. 오래된 건은 상담 시 가능 여부를 먼저 확인하세요.
* **부분취소** — 카드사·가맹점 설정에 따라 불가할 수 있습니다. 안 되면 **전액취소 후 정상 금액 재결제**가 안전합니다.
* **포스/단말기 자체 오류가 반복되면** — 카드사가 아니라 VAN사(단말기 관리업체) A/S로 접수하세요.
  * 페이히어 또는 토스플레이스
