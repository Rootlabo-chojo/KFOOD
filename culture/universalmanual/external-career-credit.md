# 📖 외부 경력 인정 채용 제도

> 시행 2026-08-01 · 공지 2026-08-05 · v1.0 대상: 실장·부실장 공석 업장 / 소관 @본사-조병조-CEO

### 1️⃣ 배경과 원칙

매장에서 실장 1명이 내부 육성으로 나오기까지 최소 1\~2년이 걸린다. 그사이 관리자 공석이 생기면 부담은 남은 직원과 지점장이 떠안는다. 반대로 실력 있는 외식업 경력자는 신입 연봉으로는 지원 자체를 하지 않는다. **외부 채용을 하지 않는 것도 비용이고 리스크다.**

| 3가지 원칙                                |
| ------------------------------------- |
| 직책자는 **사내 경력자 우선**                    |
| 외부 경력자라도 **내부 경력자보다 높은 조건을 제안하지 않는다** |
| 구성원 설명·논의 후 경영진 승인. **결정 후 통보는 금지**   |

> 이 제도가 실패하는 문장은 하나다 — _"내가 준비하던 자리에 갑자기 밖에서 사람이 왔습니다."_ **외부 1명을 얻고 내부 1명을 잃으면 산술적으로 손해다.** 성과는 신규 입사자가 아니라 **기존 인원의 잔류**로 측정한다.

***

### 2️⃣ 채용 가능 요건 — 4개 전부 충족

| 요건                                          |
| ------------------------------------------- |
| 실장 또는 부실장이 **공석인 업장**일 것                    |
| **사내 공모·사내 인원 확인을 우선** 진행 (인사 공지 채널 게시)     |
| **6개월 이내 직책 변경이 가능한 인원이 없을 것** — 있으면 **금지** |
| **매장당 최대 1명**                               |

※ 지점장은 **적용 제외** (투자·성과급 계약 별도 체계)

```
→ 지점장 발의 → 경영진 1인 이상 검토 → 대표 최종 승인
→ 입사 · 수습 30일 → 내부 평가
→ 경영진 1인 이상 동의 → 대표 확인 → 직책·경력 적용
```

* **승인 없이 체결된 경력수당 조항은 무효, 지급액은 회수 대상**

### 5️⃣ 경력 인정과 검증

| 직책  | 최대  | 경력수당     | 조건                  |
| --- | --- | -------- | ------------------- |
| 실장  | 2년차 | 300,000원 | **관리자 직책**으로서 2년 이상 |
| 부실장 | 1년차 | 150,000원 | **관리자 직책**으로서 1년 이상 |

**단순 근무 경력이 아니라 관리자 직책 경력이다.**

**제출 서류 3종** — ① 근로소득 원천징수영수증(**주민번호 마스킹**) ② 국민연금 가입증명서 또는 건보 자격득실확인서 ③ 경력증명서(**직책 명시**) ①은 연 단위 발급이라 개월 수가 부정확하고 직책이 없다. ②가 근속을, ③이 직책을 확인한다.

**인사 검증 필수** — 경력증명서에 기재된 **실제 매장에 회사가 직접 확인**(재직기간 / 실제 직책 / 관리 범위 / 퇴사 사유). 신청서에 일자·상대·요지 기재. 검증 불가 시 대체 확인하되 **1단계 하향**. 4대보험 미가입 사업장 경력은 **미인정**.

**허위 시** — 경력수당 **전액 회수** + 근로계약 **취소·해지 대상**

**정합 규칙** — 외부+사내 합계 **2년(30만) 초과 불가** / 적용 승인일 **익월 급여부터** / **소급 없음** / **연봉 재협상 기산점은 입사일 기준 사내 근속 24개월**(인정 연차와 무관)

### 6️⃣ 보상 — 내부 · 외부 비교표

> 구성원 설명 시 말로 하지 말고 이 표를 사용한다. **개인별 급여액은 공개하지 않는다.**

| 구분               | 현금        | 법인카드    | 총 상당액         | 판정             |
| ---------------- | --------- | ------- | ------------- | -------------- |
| 내부 실장 (근속 2년+)   | 3,300,000 | 400,000 | **3,700,000** | 기준선            |
| 외부 실장 (2년차, 최대)  | 3,300,000 | 400,000 | **3,700,000** | **동일 · 초과 없음** |
| 내부 부실장 (근속 2년+)  | 3,250,000 | 350,000 | **3,600,000** | 기준선            |
| 외부 부실장 (1년차, 최대) | 3,100,000 | 350,000 | **3,450,000** | **15만 원 낮음**   |

※ 수습 30일 — 실장 현금 `3,000,000` / 부실장 `2,950,000`, 법인카드 미발급 ⚠️ 공고·계약서는 반드시 **「현금 지급액 + 법인카드 한도」 분리 표기**. 분쟁은 금액이 아니라 표기 방식에서 생긴다.

**공고 문구(복붙)** — `현금 월 300~330만 원 + 법인카드 월 40만 원 → 총 340~370만 원 상당 / 인센티브·복지 적용 시 400만 원 이상 가능 / 최초 30일 수습이며 경력 인정은 이후 평가·검증으로 확정`

### 7️⃣ 내부 합의 — 이 제도의 핵심

전원 만장일치는 요건이 아니다. 다만 **직책을 준비하던 인원과 경력 보유 인원의 동의는 반드시 필요하다.**

**채용 전 4단계** ① 사실 공유(공모 결과 포함) ② 직책 준비 인원에게 **승진 시점·조건을 날짜로 제시** ③ 외부가 내부보다 높지 않다는 사실 설명(6️⃣번 표) ④ 의견·반대 기록 → '언젠가'로 답하면 면담이 아니라 회피다. 기록되지 않은 반대는 소문으로 돌아온다.

**직책 부여 시 이의 접수** → **부여 즉시 홀드** → 관리자 선 조율 → 미해결 시 **경영진 면담 후 최종 결정**

**직책 준비 인원 확약 4가지** — 승진 요건 명문화 / 다음 공석 시 내부 우선 / 6개월 내 심사 시점 확약 / 분기 1회 진행 점검

**체크리스트** (신청서 첨부, 미완성 시 승인 불가) ① 사내 공모 게시 ② 6개월 내 직책 변경 가능 인원 부재 확인 ③ 경력 보유 인원 동의(성명·일자) ④ 전원 설명 완료 ⑤ 의견·반대 기록 ⑥ 확약 4가지 전달

### ❓ FAQ

**Q. 이제 내부 승진은 어려워지나요?** — 아닙니다. 사내 경력자 우선이며, 사내에서 채워지지 않은 경우에만 발동합니다. **6개월 이내 직책 변경 가능 인원이 있으면 외부 채용 자체가 금지**됩니다.

**Q. 밖에서 온 사람이 저보다 많이 받나요?** — 받지 않습니다. 실장 기준 외부 최대치는 사내 2년 근속자와 **동일**하고, 부실장은 사내 근속자가 **월 15만 원 더** 받습니다.

**Q. 외부 입사자는 수습 없이 바로 직책인가요?** — 아닙니다. **최소 30일은 신입과 동일한 수습 계약**이며 경력수당·법인카드가 없습니다.

**Q. 경력 인정은 서류만 내면 되나요?** — 아닙니다. 서류 3종과 함께 **실제 근무했던 매장에 회사가 직접 인사 검증**을 진행합니다.

**Q. 낮게 인정받으면 영영 그대로인가요?** — 조건부 판정은 **3개월 후 재평가**로 상향 가능합니다. 총 상한은 변하지 않습니다.

**Q. 반대하면 채용이 무산되나요?** — 전원 동의를 요건으로 하지는 않지만 **경력 보유 인원의 동의는 필수**입니다. 직책 부여 시점에 이의가 접수되면 **부여는 홀드**되고, 관리자 선에서 해결되지 않으면 경영진 면담 후 결정합니다.
