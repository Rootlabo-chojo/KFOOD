#### 2️⃣ 받는 조건 (트리거)

샤플 데이터 기준 다음 **3가지 조건을 모두 충족**해야 합니다.

**① 지각 0회**

* **정의**: 샤플 출근 체크 시각 > 예정 출근 시각
* **1분이라도 지각 시 즉시 탈락**
* 네트워크 지연·기기 오류 등에 대한 이의 제기 불가 (샤플 기록이 최종)

**② 무단결근 0회**

* **정의**: 샤플에 사전 등록 없이 출근 미체크
* 1회라도 발생 시 탈락
* 사전 통보 기준: 출근 1시간 이전, 슬랙 매장 채널 + 직속 상사 DM

**③ 휴무 등록 완벽**

* **정의**: 샤플 기준 D-3일 전까지 휴무 등록 완료
* **변경 횟수 = 0회** (변경 시 탈락)
* 시스템 외 구두 변경 무효

***

#### 3️⃣ 출근 의무 면제 사유

다음 사유는 "면책"이 아니라 **출근 의무 자체가 없는 상태**입니다.

| 사유                | 처리 방식                   |
| ----------------- | ----------------------- |
| 사전 승인 연차 / 휴가     | 샤플에 사전 등록 → 출근 의무 없음    |
| 사전 등록 병가 (진단서 첨부) | 샤플에 등록 → 출근 의무 없음       |
| 사전 등록 경조사 휴가      | 샤플에 등록 → 출근 의무 없음       |
| 격리 / 천재지변         | 샤플 사후 등록 + 증빙 → 검토 후 처리 |
| 회사 지시 외근 / 출장     | 샤플 외근 등록 → 출근으로 인정      |

> **핵심**: 모든 처리는 샤플에 기록되어야 합니다. 시스템 기록 = 진실의 단일 출처.

#### 4️⃣ 보상

**개인 보상**

**10만원** (전 직원 균일)

**매장 전원 달성 시 추가 회식비**

* **1인당 3만원 × 매장 인원수**
* 예시: 8명 매장 → 24만원 회식비
* 회사 법인카드 사용 (비과세)
* 익월 말일까지 사용 (미사용분 환원)

**본사 전원 달성 시 추가 회식비**

* 본사 정직원 6명 전원 달성 시 → **18만원 회식비**

#### 8️⃣ 자주 묻는 질문 (FAQ)

**Q1. 5분 지각 한 번도 안 되나요?**

네. **무관용**입니다. 1분이라도 지각하면 그 달은 탈락입니다.

**Q2. 갑자기 아프면 어떻게 하나요?**

출근 1시간 전까지 슬랙으로 통보하고, 출근 후 또는 다음 날 진단서를 샤플에 등록하면 출근 의무 면제로 처리됩니다.

**Q3. 수습 기간인데도 받을 수 있나요?**

네. **수습 직원도 동일하게 적용**됩니다.

**Q4. 2월 5일에 입사했는데 2월 인센티브를 받을 수 있나요?**

아니요. **매월 1일에 재직 중**이어야 자격이 발생합니다. 첫 자격은 3월부터입니다.

**Q5. 매장 전원이 받아야 회식비가 나오나요?**

네. 한 명이라도 탈락하면 매장 회식비는 없습니다. 다만 **개인 인센티브는 자격자에게 정상 지급**됩니다.

**Q6. 회식비를 안 쓰면 어떻게 되나요?**

익월 말일까지 사용해야 하며, 미사용분은 회사로 환원됩니다.

**Q7. 샤플 시스템에 오류가 생기면 어떻게 하나요?**

김지현 매니저가 매월 1\~3일 검토 기간에 확인합니다. 시스템 다운타임 등 명백한 시스템 측 오류는 정상 처리됩니다.

**Q8. 외근·출장은 어떻게 처리되나요?**

**샤플에 외근/출장 사전 등록**하시면 출근으로 인정됩니다. 등록 누락 시 무단결근으로 처리될 수 있으니 반드시 등록 부탁드립니다.
